# Technologies Used

## Core Framework & Language
- **React 18.3.1** - UI library for building component-based interfaces
- **TypeScript 5.5.3** - Strongly typed superset of JavaScript
- **Vite 5.4.2** - Fast build tool and development server

## Styling
- **Tailwind CSS 3.4.1** - Utility-first CSS framework
- **PostCSS 8.4.35** - CSS transformation tool
- **Autoprefixer 10.4.18** - Automatic vendor prefixing

## Icons & UI
- **Lucide React 0.344.0** - Icon library with clean, consistent SVG icons

## Backend & Database
- **Supabase** - Backend-as-a-Service platform
- **@supabase/supabase-js 2.57.4** - Official Supabase JavaScript client
- **PostgreSQL** - Underlying relational database (via Supabase)
- **Row Level Security (RLS)** - Database-level access control

## Development & Code Quality
- **ESLint 9.9.1** - JavaScript/TypeScript linter
- **typescript-eslint 8.3.0** - TypeScript support for ESLint
- **eslint-plugin-react-hooks** - Enforces React Hooks rules
- **eslint-plugin-react-refresh** - Hot reload safety checks

## Build Configuration
- **@vitejs/plugin-react 4.3.1** - React plugin for Vite
- **tsconfig** - Separate TypeScript configs for app and node contexts

## Fonts
- **Playfair Display** - Serif display font used for headings
- System font stack for body text

## Design Patterns
- Single Page Application (SPA) with client-side navigation
- Component-based architecture with clear separation of concerns
- Responsive design with mobile-first breakpoints
- Custom color ramps (primary, gold) via Tailwind theme extension

## Assets
- Local static images served from `/public`
- Pexels stock photography for supplementary imagery
